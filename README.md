# LivePin for Obsidian

Pins the current note, or the selected text, to the iPhone Lock Screen as a Live Activity.
Requires the LivePin iPhone app (Jombazi iOS Repo).

- **📌 button** at the top of every note: one tap pins it; it turns blue while pinned and a second tap unpins that note.
- Command **Pin note to Lock Screen** (also in the note and editor menus). Selected text is pinned if there is a selection; otherwise the whole note.
- The first image in the note (or in the selected text) is shown as a thumbnail on the card.
- Command **Unpin everything from Lock Screen**.

LivePin opens briefly, pins the note, then returns to the same note in Obsidian.
iOS ends a Live Activity after 8 hours (it can stay on the Lock Screen up to 4 more hours).

Install with BRAT: `Jombazi/obsidian-livepin`.
